Quick Reference
Kraken Server — IPv4 of the machine running KrakenSDR software. Station ID creates unique TAK identifiers when running multiple radios.
TAK Destination — IPv4 and port of your TAK Server input. Multicast additionally broadcasts to 239.2.3.1:6969 for direct client reception.
DOA Exclusion — Bearings inside the shaded wedge are suppressed. Useful when a known transmitter is in a fixed direction.
Persist Lines — Off: one line is drawn and updated each cycle. On: each bearing generates a new line, leaving a history of readings.
Line Length — Length of the DOA bearing line drawn in TAK, in kilometers. Default is 6 km.
